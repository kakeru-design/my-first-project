# お問い合わせ

運勢日和へのお問い合わせは、下記のフォームからお願いいたします。

【ここにお問い合わせフォームを設置(例:Contact Form 7 のショートコード)】

## ご利用にあたって
- 内容を確認のうえ、原則として【◯営業日】以内にご返信いたします。内容によってはご返信できない場合や、お時間をいただく場合があります。
- **個別の占い・鑑定のご依頼にはお応えしておりません。** 個別のご相談は、当サイトで紹介している占いサービスをご利用ください。
- 紹介しているサービスの利用方法・契約・返金などについては、各サービスの窓口へ直接お問い合わせください。
- 入力いただいた個人情報は、お問い合わせへの対応にのみ利用します。詳しくは[プライバシーポリシー](【プライバシーポリシーURL】)をご覧ください。

## フォームの入力項目(設置時の目安)
- お名前(ニックネーム可)【必須】
- メールアドレス【必須】
- お問い合わせの種類(サイトについて / 掲載内容の誤り / 広告掲載のご相談 / 有料サービスについて / その他)
- お問い合わせ内容【必須】
- プライバシーポリシーへの同意チェック【必須】
