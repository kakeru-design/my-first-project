# 固定ページ原稿(運営者情報・規約類)

WordPress の「固定ページ」にそのまま貼り付けて使う原稿です。【】で囲んだ部分は、公開前に必ず埋めてください。

> **公開前に、法律の専門家(弁護士・行政書士など)の確認を推奨します。** 特に「特定商取引法に基づく表記」「利用規約」は、有料サービスの内容が決まった段階で確認を受けてください。法令やガイドラインは改正されることがあるため、消費者庁・個人情報保護委員会の最新情報もあわせて確認してください。

## WordPress への設置手順
1. 固定ページを作成し、各ファイルの本文を貼り付ける(ブロックエディタに Markdown を貼ると見出し・表に変換される)。先頭の `>` で始まる注記(作業メモ)は削除する。
2. 外観 → メニュー で「フッターナビ」に上表の「○」のページを登録する。
3. お問い合わせページにフォームを設置する(例:Contact Form 7)。送信先メールアドレスは公開しない。
4. 各ページ内のリンク【◯◯ページURL】を、実際のページURLに置き換える。

## 個人運営で住所・電話番号を公開したくない場合
- **運営者情報ページ**:法律上の表示義務はないため、「請求があった場合、遅滞なく開示」またはお問い合わせフォームへの案内で問題ありません。
- **特定商取引法に基づく表記**(有料サービスを始める場合のみ必要):一部の事項は「請求があれば遅滞なく開示する」旨を表示することで省略できる場合があります。詳しくは `uranai/tokushoho.md` 末尾の注記を参照してください。ただし、決済代行事業者の審査で住所・電話番号の表示を求められることがあります。
