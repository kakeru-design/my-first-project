# 運勢日和 SNS紹介投稿テンプレート(X / Threads / Instagram)

毎日の投稿文は、WordPressのダッシュボード「今日のSNS投稿文(月詠灯)」と「ツール → SNS投稿文」に自動で出ます。
各投稿の「コピー」「Xで投稿する」「Threadsで投稿する」を押すだけで使えます(管理者のみ表示)。

## 毎日出る投稿(XとThreadsは同じ本文)

| 投稿 | 出る日 | リンク先 |
|---|---|---|
| 毎朝のランキング | 毎日 | トップ |
| 今日が誕生日の人へ | 毎日 | /tanjobi/{月}-{日}/ |
| 週間ランキング | 月曜 | /shukan/ |
| 新月・満月 | 前日と当日 | /tsuki/ |

## 紹介投稿(曜日ごとに1本。X / Threads / Instagram の3種類)

| 曜日 | 紹介するページ | リンク先 | PR表記 |
|---|---|---|---|
| 月 | なし(週間ランキングを投稿) | — | — |
| 火 | 12星座の相性(今日1位の星座と、相性の良い星座のペア) | /aisho/{a}-{b}/ | 不要 |
| 水 | 九星気学の無料診断(今月の中宮の星つき) | /#kyusei | 不要 |
| 木 | 開運グッズ(今日1位のラッキーアイテムつき) | /kaiun/ | **必要(#PR)** |
| 金 | 誕生日別の性格(今日の誕生日を例に) | /tanjobi/ | 不要 |
| 土 | 月の満ち欠け(今日の月齢・月の呼び名・次の新月/満月) | /tsuki/ | 不要 |
| 日 | 今日1位の星座ページ | /seiza/{星座}/ | 不要 |

### テンプレート(例:文面は日付・順位によって自動で変わります)

**火・相性**
- X:「🌙今日1位の天秤座と、相性の良い双子座。/二人は「最高の相性」の関係で、相性度は96%です。/(恋愛のひとこと)/恋愛・友情・仕事の相性はこちらから。/URL/#星座占い #相性占い」
- Threads: 1位の紹介 → 関係と相性度 → 総合 → 恋愛 → 二人がうまくいくコツ → 「78通りの相性をすべて載せています」→ URL
- Instagram:「双子座と天秤座の相性は96%🌙」→ 恋愛 → コツ →「78通りの相性は、プロフィールのリンクから」→ ハッシュタグ8個

**水・九星気学の無料診断**
- X:「🌙生年月日を入れるだけで、あなたの本命星がわかります。/今日の運勢と11月の吉方位もいっしょに。/11月は八白土星が中央に入る月です。/URL/#九星気学 #吉方位」
- Threads: わかること5項目の箇条書き +「入力した生年月日は保存しません」
- Instagram: わかること3項目 +「診断はプロフィールのリンクから」

**木・開運グッズ(#PR)**
- 先頭に「#PR」。今日1位の星座のラッキーアイテム → 開運グッズの紹介 → URL
- Threads には「持つだけで何かが変わる、というものではありませんが…」を入れて、効果を断定しない
- Instagram には「※商品リンクにはAmazonアソシエイトのリンクを含みます」を入れる

**金・誕生日別の性格**
- 「🎂誕生日別の性格を、366日ぶんまとめました。」→ 今日の誕生日の星座と性格 → URL

**土・月の満ち欠け**
- 「🌙今日の月は月齢11.8、満ちていく月です。」→ 時期のひとこと → 次の新月/満月 → URL
- 月の呼び名: 新月 / 三日月 / 上弦の月 / 満ちていく月 / 満月 / 欠けていく月 / 下弦の月 / 有明の月

**日・今日1位の星座ページ**
- 「🌙今日1位の乙女座さんへ。」→ 今日の流れ →(Threads)恋愛・仕事・金運の星とおすすめの時間帯 → URL

## 運用ルール

### PR表記(ステマ規制)
- 開運グッズ(/kaiun/)など、**広告(Amazon・電話占い)への誘導を含む投稿は、X・Threads・Instagramすべてで先頭に「#PR」**を付ける(木曜の紹介投稿は自動で付く)。
- Instagramでブランドから依頼を受けた投稿をする場合は「タイアップ投稿」ラベルも使う。
- サイト内のページ紹介だけの投稿(相性・誕生日・月・星座ページ・九星気学)は不要。

### 投稿頻度の目安
| SNS | 毎日 | 週 |
|---|---|---|
| X | 朝7時ランキング、昼に誕生日、紹介投稿1本 | 月曜に週間ランキング |
| Threads | Xと同じ本文でランキング、紹介投稿1本(長めの語りかけ版) | — |
| Instagram | ストーリーズでランキング | フィード2〜3本(紹介投稿のキャプションを使い、画像はMuseが作成) |

### ハッシュタグ
- X: 1投稿2〜3個(多すぎると読みにくい)
- Threads: 0〜1個(本文の語りかけを優先)
- Instagram: 5〜10個。必ず「#運勢日和」を入れる
- よく使うもの: #今日の運勢 #星座占い #12星座占い #九星気学 #吉方位 #相性占い #誕生日占い #月の満ち欠け #新月 #満月 #開運 #開運習慣

### 文面のルール(スタイルガイドより)
- 一人称は「わたし」、やわらかい「です・ます」。断定しない(必ず・絶対・100%は使わない)
- 絵文字は🌙✦🕯中心で、1投稿2つまで
- 健康・お金・法律の深刻な相談には占いで答えず、専門家への相談をすすめる
- 成人向けサイトなど、運勢日和以外の運営サイトとは一切つなげない

### 文字数
- X: 280(日本語は1文字2、URLは23として計算)以内に自動調整
- Threads: 500文字以内に自動調整
- 1年分(365日)の自動チェックで、X最大271、Threads最大375文字
