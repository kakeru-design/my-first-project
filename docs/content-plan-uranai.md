# 占いサイト コンテンツ計画

## 収益の柱
- **電話占い・チャット占い**(ASP案件: 新規会員登録・初回鑑定で成果。単価が比較的高い)
- 補助: 占い本・パワーストーン等の物販

## サイト構成(カテゴリ)
| カテゴリ | 役割 | 例 |
|---|---|---|
| 電話占い比較 | 収益記事(比較・ランキング) | 電話占いおすすめランキング / 初回無料特典まとめ |
| サービス別口コミ | 収益記事(指名検索) | 「サービス名 口コミ」「サービス名 当たる先生」 |
| 悩み別 | 集客→比較記事へ送客 | 復縁 / 片思い / 不倫 / 仕事・転職 / 結婚 |
| 占術解説 | 集客(ビッグワード周辺) | タロット / 霊視 / 四柱推命 / 西洋占星術 |

## 記事テンプレート(比較記事)
```
[pr_notice] ← 自動挿入されるので通常は不要
導入(読者の悩み → この記事でわかること)
## 結論:おすすめ3選
[aff_ranking slugs="uranai-a,uranai-b,uranai-c"]
## 比較表
[aff_table slugs="uranai-a,uranai-b,uranai-c"]
## 選び方のポイント
## 各サービスの詳細(実際に利用した体験・スクショ)
[aff_button slug="uranai-a"]
## よくある質問
## まとめ
[aff_button slug="uranai-a"]
```

## 注意点
- 「必ず当たる」「100%復縁」など断定・誇大表現は避ける(景品表示法・ASPの規約違反になりやすい)
- 料金や特典は変わりやすいので、記事に更新日を残し、定期的に確認する
- 口コミ記事は実体験を中心に。他サイトからの口コミ転載はしない
