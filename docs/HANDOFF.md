## 3. 反映の手順(デプロイ)
1. コードを変更したら、**そのテーマ・プラグインのバージョン番号を上げる**(テーマは style.css の `Version`、プラグインはヘッダーの `Version` と CSS の enqueue のバージョン)。
2. `python3 scripts/build-zips.py` で `dist/*.zip` を作る。
3. ユーザーが WordPress の管理画面で「アップロードしたもので現在のものを置き換える」で入れ替える。
4. 独自ページのURLを追加したときは、`pages.php` の `UT_REWRITE_VERSION` を上げる(自動でリライトルールを更新)。念のため「設定 → パーマリンク → 変更を保存」も案内する。
5. 公開サイトで反映を確認する(CSSの `?ver=` がバージョン番号になっている)。
6. 変更は作業ブランチにコミットし、プルリクエストで `main` に取り込む。

ローカル確認は WordPress が使えない環境のことが多いため、WordPress関数のスタブを書いたPHPで出力HTMLを作り、Playwrightでスマホ幅(390px)のスクリーンショットを撮って確認してきた。

## 4. 守るべきルール(法令・規約・世界観)
- **PR表記(ステマ規制)**: 広告を含むページ・枠・SNS投稿には「PR」「#PR」を付ける。共通プラグインが記事冒頭に自動挿入し、各枠にも表示している。
- **広告リンクをSNSに直接貼らない**: SNSからはサイトのページへ誘導する(例: /#soudan)。
- **占いの表現**: 「必ず」「絶対」「100%」「霊視で未来がわかる」などの断定・誇大表現、不安をあおる表現、健康・お金・法律の断定は使わない。石や色の意味は「〜と言われています」。
- **評価の星**: 根拠のない点数は付けない。報酬の高さで順位を決めない。
- **月詠灯**: AIで生成したキャラクター(紫のフードの水彩イラスト)。一人称「わたし」、やわらかい「です・ます」、絵文字は🌙✦🕯を中心に1投稿2つまで。詳細は `docs/sns/muse-brief.md`。
- **ファンズピック**: 18歳未満閲覧禁止の年齢確認ゲート、`rating=adult` メタ、「FANZA(DMM)の公式サイトではない」旨を表示。Amazon・楽天・A8など一般ASPは成人向けサイトで使えない。
- **女優の紹介文**: 実在の人物なので、体型・私生活・確認できない経歴には触れない。
