# 一粒万倍日にやるといいこと・避けたいこと

カレンダーや占いのサイトで「一粒万倍日(いちりゅうまんばいび)」という言葉を見かけたことはありませんか。何か新しいことを始めたくなったとき、縁起の良い日を選びたいと感じる方は多いと思います。この記事では、一粒万倍日とはどんな日なのか、やるといいとされていること・避けたほうがいいと言われていることを、やさしくまとめました。2026年12月16日は、一粒万倍日の中でもさらに特別な日が重なるので、あわせてご紹介します。

## 一粒万倍日とは

一粒万倍日は、「一粒の籾(もみ)が、万倍にも実って大きな稲穂になる」という言い伝えから名付けられた、暦の上で縁起が良いとされる日です。この日に始めたことは、小さな一歩でも、やがて大きく育っていくと言われています。暦の計算方法によって、月に4〜6回ほどめぐってきます。

もともとは農業にまつわる言い伝えですが、今では「始めごと」や「お金にまつわること」に向いている日として、広く親しまれています。

## 一粒万倍日はいつ?調べ方

一粒万倍日がいつになるかは、旧暦の節目である「節月(立春・啓蟄などの節入りで区切られる月)」と、その日の十二支の組み合わせによって決まります。計算のルールが少し複雑なため、ご自身でカレンダーから調べるよりも、占いサイトの吉日カレンダーなどでまとめて確認する方が簡単です。先ほどお伝えしたとおり月に4〜6回ほどありますので、「今月はいつだろう」と気になったときに、気軽にチェックしてみてください。運勢日和では[2026年12月の吉日カレンダー](https://unsei-biyori.com/kichijitsu/2026/12/)や[2027年の天赦日・一粒万倍日の一覧](https://unsei-biyori.com/kichijitsu/2027/)も、月ごと・年ごとにまとめています。

## 一粒万倍日にやるといいと言われていること

一粒万倍日は、「何かを始める」ことに向いているとされる日です。たとえば、次のようなことが候補として挙げられます。

- **新しいことを始める**: 勉強や習い事、仕事の新しいプロジェクトなど、始めたいことがあればこの日を選んでみるのも一つの方法です。
- **口座開設・貯金を始める**: お金が万倍に実るという言い伝えから、新しい口座を開いたり、貯金を始めたりするのに良いとされています。
- **お財布を新調する・使い始める**: 新しいお財布をおろす日としても人気があります。
- **目標を書き出す**: 手帳やノートに、これからの目標を書いてみるのもおすすめです。気持ちを新たにするきっかけになるかもしれません。

これらは「絶対にうまくいく」ことを保証するものではありませんが、新しい一歩を踏み出すときの、ちょっとした後押しとして活用してみるのも良いのではないでしょうか。

## 一粒万倍日に避けたほうがいいと言われていること

一方で、一粒万倍日には「人からお金を借りること」は避けたほうがいいという言い伝えがあります。これは、「良いことだけでなく、借りたお金(マイナスの事柄)も万倍に増えてしまう」という考え方からきているものです。

大きな買い物やローンの契約そのものがいけないわけではありませんが、「借りる」という行為についてはこの日を避ける方もいるようです。気になる方は、少しスケジュールをずらしてみるのも一つの選択肢かもしれません。

## 一粒万倍日が他の吉日と重なると

一粒万倍日は、「天赦日(てんしゃび)」や「甲子(きのえね)の日」など、他の縁起の良い日と重なることがあります。このように複数の吉日が重なる日は、特に縁起が良いとされています。

## 2026年12月16日は特別な一粒万倍日

2026年12月16日(水)は、一粒万倍日であることに加えて、暦の上で最上の吉日とされる「天赦日」、そして60日に1回めぐってくる「始まりの日」である「甲子の日」が重なる、年に数えるほどしかない特別な日です。

新しいことを始めたい、気持ちを切り替えたいと考えている方にとっては、一つの目安として意識してみるのも良いかもしれません。もちろん、この日を逃してしまっても、一粒万倍日は月に何度もめぐってきますので、焦らずご自身のタイミングを大切にしてくださいね。

## よくある質問

**Q. 一粒万倍日と天赦日、どちらを優先すればいいですか?**
どちらも縁起が良いとされる日ですが、天赦日は年に5〜6回ほどしかめぐってこない、暦の上でも特に特別な日とされています。両方が重なる日があれば、その日を選ぶ方も多いようです。ただ、どちらも「必ずこの日でなければいけない」というものではないので、ご自身の都合の良いタイミングを優先しても問題ありません。

**Q. 一粒万倍日に買い物をするのは良くないですか?**
買い物そのものは問題ないとされています。避けたほうがいいと言われているのは「お金を借りること」です。お財布や口座を新調するなど、お金にまつわる良い意味での始めごとは、むしろ向いているとされています。
