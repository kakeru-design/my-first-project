# アダルトサイト コンテンツ計画

## 収益の柱
- **アダルト動画配信サービス**(月額見放題・単品購入の成果報酬)
- 補助: 大人向けグッズ通販、成人向けマッチング等(案件ごとに規約を確認)

## まず確認すること(重要)
- **ASPの選定**: A8.net等の一般ASPは成人向けサイトの登録・掲載を禁止していることが多い。
  アダルト専用のASP、または配信サービス公式のアフィリエイトプログラムを利用する。
- **Google AdSense は利用不可**(成人向けコンテンツはポリシー違反)。
- **サーバー**: レンタルサーバーによってはアダルトサイト不可。規約で可否を確認してから契約する。
- **画像のモザイク・掲載基準**: わいせつ物頒布にあたる画像は掲載しない。ASPが提供する公式素材のみを使う。
- **出会い系・マッチング案件**: 出会い系サイト規制法の対象になる場合があり、年齢確認や届出の有無を案件側で確認する。

## サイト構成(カテゴリ)
| カテゴリ | 役割 | 例 |

| サービス比較 | 収益記事 | 動画配信サービスおすすめ比較 / 無料体験まとめ |

## 最初に書く8記事
1. 動画配信サービスおすすめ比較(`[aff_ranking]` + `[aff_table]`)
2. 無料体験・お試し特典まとめ
3. 料金・支払い方法の比較(クレカ以外の選択肢)
4. 動画配信サービスA レビュー・評判
5. 動画配信サービスA 解約方法
6. 動画配信サービスB レビュー・評判
7. 安全に利用するための注意点(公式以外のサイトのリスク)

## 実装済みの配慮
- 年齢確認ゲート(30日間 Cookie で記憶)
- `<meta name="rating" content="adult">` 出力(Google SafeSearch 対応)
- フッターに18歳未満閲覧禁止の表記
- PR表記の自動挿入
